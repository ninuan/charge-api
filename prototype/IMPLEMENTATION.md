# 正式前端改造进度

检查与续改日期：2026-09-11。工作分支：`codex/workbench-redesign`。
此记录描述正式前端；`VERIFICATION.md` 描述独立的示例原型。

## 接手时已有实现

- 常用桩已切换为列表 / 详情工作台，包含端口、历史、编辑、移除、排序与提醒入口。
- 提醒和通知已有独立页面，并使用现有业务 context / API。
- 账户已有连接、通知偏好、安全和外观分区。
- 管理工作区已有总览、异常、用户、系统策略、运行、邀请和审计界面。
- 共用导航、主题与响应式样式已迁移。以上为代码接入情况，不代表所有业务流程均完成验收。
- 基线类型检查和 49 个测试文件中的 174 项测试通过。

## 本次续改

- 修复共用地址参数更新：选桩、选口、筛选等操作曾只改变 URL、不更新 `useSearchParams`。按当前 Next.js 原生 History API 约定传入 `null`，由框架维护内部历史状态，恢复页面同步与浏览器后退。
- 首次加载失败时，列表内显示错误与重试；手机列表不再误显示为空账户。
- 部分刷新失败、设备离线时统一标记旧快照；端口详情不再将旧功率和空闲信息表述为当前状态。
- 没有端口数据的设备显示“尚未读取”，即使在线标记为 true，也不展示零空闲数。
- 新增独立的工作台浏览器回归配置。所有 API 请求拦截为测试数据，不依赖或修改真实账户。
